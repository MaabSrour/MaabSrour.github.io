# Maab Srour Portfolio — Version 3.0

Complete bilingual portfolio for GitHub Pages.

## Publish
Upload **all files and folders** to the root of the `MaabSrour.github.io` repository, replacing the old files.

## CV
Add your English CV as `files/Maab-Srour-CV-English.pdf`.
You can later add an Arabic CV and change the link in `index.html`.

## Included
- English / Arabic toggle
- Light / dark mode
- Responsive mobile design
- Animated role text and counters
- About, expertise, research, projects, career journey, tech stack and contact
- Research details modal
- SEO and accessibility basics
