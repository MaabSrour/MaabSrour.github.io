# Maab Srour Portfolio v2

This version already includes the approved portrait image.

## Uploading to GitHub
1. Delete the old files from the repository.
2. Extract this ZIP.
3. Upload all folders and files exactly as they appear:
   - index.html
   - css/
   - js/
   - images/
   - files/
4. Commit changes.
5. Wait one minute and refresh with Ctrl + F5.
