# Maab Srour Portfolio

## Files
- `index.html` — website content
- `style.css` — colours and layout
- `script.js` — bilingual toggle and mobile menu
- `profile-placeholder.svg` — replace this with your photo

## Publish on GitHub Pages
Upload all files to the root of the `MaabSrour.github.io` repository.

## Add your photo
1. Rename your photo to `profile.jpg`.
2. Upload it to the repository.
3. In `index.html`, replace:
   `profile-placeholder.svg`
   with:
   `profile.jpg`

## Add CV files
Upload:
- `Maab-Srour-CV-English.pdf`
- `Maab-Srour-CV-Arabic.pdf`

The current CV button points to the English PDF. You can later add two separate buttons.
